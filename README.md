# Airbnb Clone — React + Vite

This project implements the three required desktop views from the take-home task:
1. Listing page
2. Photo tour
3. Single-photo lightbox with previous/next and keyboard navigation

## Requirements
- Node.js 18+ (Node 20 LTS recommended)
- VS Code

## Run in VS Code

### 1. Extract the ZIP
Unzip the project and open the `airbnb-clone-app` folder in VS Code.

### 2. Open terminal
In VS Code: **Terminal → New Terminal**

### 3. Install packages
```bash
npm install
```

### 4. Start development server
```bash
npm run dev
```

Vite will print a local URL, usually:
`http://localhost:5173`

Open that URL in Chrome.

### 5. Production build
```bash
npm run build
```

### 6. Preview production build
```bash
npm run preview
```

## Important files
- `src/main.jsx` — React application and interactions
- `src/styles.css` — layout and styling
- `src/data.json` — editable listing data and photo URLs
- `package.json` — dependencies/scripts
- `docs/architecture.md` — production architecture notes
